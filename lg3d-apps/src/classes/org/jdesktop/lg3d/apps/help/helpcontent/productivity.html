Office and Productivity

The Office and Utilities groups hold the everyday productivity tools: mail, an agenda, an address book, a PDF reader, an organisation chart, a calculator, archiving, file management and search. They are plain Swing applications, so each runs in the 3D desktop and as an internal frame in the 2D and Swing desktops.

Mail

Mail is a real IMAP / SMTP client. It is described with the other networked applications in Internet and the Web.

Agenda

Agenda is a week planner. It shares its store with the Contacts address book, the messenger and the video conference, and it can be opened straight to a day: double-click a date in the taskbar calendar and the Agenda jumps to it.

Contacts

Contacts is the desktop address book — a full create / read / update / delete manager over a shared store that the Agenda, Messenger and Video Conference also read.

PDF Viewer

PDF Viewer reads and navigates PDF documents (built on Apache PDFBox). It lives in the Office group and is a common target for file associations, so double-clicking a PDF in the File Manager can open it here.

Chart (organisation chart)

Chart draws an organisation chart. Like the Agenda it has both a 3D view and a plain Swing panel for the 2D desktop, sharing one model.

Calculator

Calculator is a scientific calculator with an expression history and a memory register.

Archive

Archive browses, extracts and creates archives of every common open format — ZIP, 7z, TAR, tar.gz / bz2 / xz, gz, bz2, xz, CPIO and AR — over a path-traversal-hardened engine.

File Manager

File Manager browses and manages files and folders. It is the desktop's two-pane file browser and the usual way to open a document in the application associated with its type.

Search

Search finds files and text across the system. It is the target of the desktop-wide Ctrl+Shift+F shortcut, so you can summon it from anywhere.

Weather and Periodic Table

Weather shows current conditions and a forecast from the free Open-Meteo service. Periodic Table (in the Education group) is a reference table of the 118 elements.

Scheduling

Recurring jobs and a task scheduler are configured from the Control Center's Schedule and Task Scheduler panels — see Customizing the Desktop.
