Customizing the Desktop

Almost all customization is done through the Control Center (Start Menu → System). It gathers every appearance, display, input, network and system setting into one window: a list of categories on the left, and the chosen category's panel on the right. It runs in the 3D desktop and in the 2D and Swing desktops, and its changes apply live — you do not need to restart.

Note: Several categories read or change real host state through the matching system tool — Network (nmcli), Bluetooth (bluetoothctl / rfkill), Printing (lpstat), Date & Time (timedatectl), Language & Region (localectl) and Mouse & Keyboard (xset). Where a tool is not installed, that category degrades gracefully rather than failing.

Appearance

The Appearance panel carries the look of the desktop itself:

  • Window Glass — choose the Glassy or Frosted window style, and turn Rounded corners on or off. The choice applies to the desktop's window decoration.
  • Corner Logo — pick the decorative 3D model that floats in the corner of the image background: the classic Java logo or the Looking Glass mascot. This is a 3D-only setting; it swaps live, without restarting.
  • Wallpaper — choose a bundled backdrop or a Custom Image… of your own, with a preview.
  • Wallpaper Slideshow — turn the slideshow on, set how often the picture changes (10 seconds to an hour), and point it at a folder of your own images or leave it on Use Bundled. Your choices are remembered between sessions.
  • Fonts — the Swing font family and size applied to hosted application panels, so changing it re-skins the text across the desktop's Swing windows, including this Help Center.
Note: The slideshow and the wallpaper chooser take effect on the 2D and Swing desktops; on the 3D desktop the backdrop is driven by the scene manager, so those particular Appearance controls are inert there (the Corner Logo, by contrast, is 3D-only).

Customization: themes, accent and icon packs

  • System Look — choose a theme, create a New… one, or Delete a theme you added.
  • Accent — pick the desktop accent colour used by the theme.
  • Icon packs — Create Pack…, Import Pack…, Delete Pack or Use Default. The active pack reskins the application and category icons across the desktop.

Wallpapers and the 3D background

The desktop background can be one of the bundled wallpaper images, or a 3D model. Launch with -b (or the Gradle property -Pbackground3d) to use the 3D model background (pinguin.j3f) instead of a flat image. The taskbar and windows sit in front of whichever background is active.

Tip: Changes made in the Control Center apply live; you do not need to restart the desktop to see them.
