Music, Photos and Video

The Media group of the Start Menu covers everything from playing a song or a film to editing a photo, recording a screencast, tuning a guitar and burning a disc. Most of these are plain Swing applications that run in the 3D desktop and in the 2D and Swing desktops.

Note: The JDK has no MP3, video or screen-recording codec of its own. Where a format needs one, these applications play or capture it in process only for the JDK-native cases and otherwise delegate to a real external tool you already have (for example mpv, vlc, ffplay, ffmpeg). If the tool is not installed the app says so rather than failing silently.

Audio Player

Audio Player plays music, internet radio and podcasts, rips audio CDs, and browses your albums by cover. It plays the JDK-native formats (WAV, AU, AIFF) in process and hands MP3, other codecs and every network stream to an external player.

Video Player

Video Player is a VLC-style front end for movies, streams and discs. It manages a library and hands each file, stream or disc to a real external player (vlc, mpv, mplayer, totem or ffplay).

Photo Viewer

Photo Viewer is a tagged gallery built on plain Java 2D / ImageIO. It shows a thumbnail grid and a preview, and lets you tag and rate your photos; the library is stored as JSON.

Image Editor

Image Editor is a GIMP-style workspace built entirely on Java 2D: a canvas, a layers panel, drawing tools, filters and an undo stack. It needs no codec and no external tool.

Recorder

Recorder captures audio and the screen. Microphone audio is recorded natively to WAV; screen capture is handed to an external ffmpeg / avconv. Recordings and their settings are kept as JSON.

Tuner

Tuner tunes a guitar or bass from the microphone. Pitch detection (the YIN algorithm) runs genuinely in process: it opens the default capture line and streams audio into the detector, so there is nothing to install. No capture device is opened until you press Start.

Media Writer

Media Writer burns CD / DVD images and writes or clones USB keys — the tool you would use to make a bootable drive.

Paint and Image Studio

Paint is a simple drawing application; because it shows its own conventional window it runs beside the 2D desktop rather than inside it. Image Studio is a Java Advanced Imaging (JAI) editor that runs only in the 3D desktop.
