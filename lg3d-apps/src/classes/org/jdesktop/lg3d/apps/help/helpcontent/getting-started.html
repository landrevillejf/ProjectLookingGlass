Getting Started

This port of Project Looking Glass is built with Gradle and runs on JDK 21. In development mode the whole desktop is an ordinary window on your host X display, so no special window-manager setup is required.

Requirements

  • A JDK 21 toolchain (the launcher auto-detects one).
  • An X display — the DISPLAY variable, defaulting to :0.
  • A graphics stack able to run Jogamp Java 3D. If 3D is unavailable, the desktop offers the 2D desktop instead.

Launching the desktop

From the repository root, run the launcher script:

./run-lg3d.sh

This pins JDK 21, makes sure a display is present, assembles the runtime resources (icons, wallpapers, backgrounds) and starts the display server full-screen. The equivalent direct Gradle invocation is ./gradlew :lg3d-core:run.

Common launcher options

OptionEffect
-b, --background3d Use the 3D model background (pinguin.j3f).
-2, --2d Run the conventional Swing 2D (MDI) desktop.
-w, --swing Run the 2D desktop under the Metal look and feel.
-c, --clean Clean :lg3d-core before launching.
-r, --rebuild Force the runtime resources tree to be reassembled.
-x, --compositor Run lg3d as its own X11 window manager + compositor.
-h, --help Print the launcher help.

To run the small debugging window instead of the full-screen desktop, add the Gradle property -Pwindowed (for example ./run-lg3d.sh -- -Pwindowed).

Note: Anything after -- is passed straight to Gradle, so you can combine launcher options with raw Gradle properties.

Opening this Help Center

Once the desktop is up, open the Start Menu and choose Help Center under Utilities. You can also keep it open while you work: windows can be moved, rotated and parked out of the way.
