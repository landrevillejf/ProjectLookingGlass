A Tour of the Desktop

When the 3D desktop starts you are looking into a shallow three-dimensional room. Four things make up the scene:

1. The background

Behind everything is the desktop background. By default it is a flat image; launching with -b (see Getting Started) replaces it with a 3D model. The background sits at the back of the scene, so windows always float in front of it. See Customizing the Desktop to change it.

2. Windows

Applications open as panels floating in the room. Each window has a title bar along the top with minimize, maximize and close buttons, and it can be moved and turned in 3D. Everything you can do with a window is described in Working with Windows.

3. The taskbar

Along an edge of the screen sits the glassy taskbar. It holds a live thumbnail of every open window and a button for the Start Menu. Details are in The Taskbar.

4. Widgets

Small always-on gadgets — a clock, CPU and memory meters, a weather card — can live on the desktop. These are the Desktop Widgets.

Tip: Right-clicking the empty background parks your windows onto a "bookshelf" so you can see the desktop; right-clicking again brings them back. Learn this and other idioms in Mouse Gestures and Navigation.
