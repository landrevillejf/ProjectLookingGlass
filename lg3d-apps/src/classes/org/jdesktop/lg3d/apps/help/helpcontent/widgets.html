Desktop Widgets

Widgets are small, always-available gadgets that live on the desktop rather than in a window. They are provided by a pluggable widget framework, so new widgets can be added without changing the desktop itself.

Built-in widgets

WidgetShows

CPUProcessor load.

WeatherA weather card parsed from a JSON feed.

The Widget Gallery

The Widget Gallery lets you browse the available widgets and place them. It runs both as a 3D desktop window and as a plain Swing panel in the 2D desktop, so you can manage widgets in either mode.

How widgets are discovered

Widgets are contributed through providers registered with the standard Java ServiceLoader mechanism. A third party can add widgets simply by putting a jar with the right service registration on the desktop classpath — no changes to the widget module or to the desktop core are needed.

Tip: Each widget declares a preferred size and a short description; the gallery uses these to lay the widgets out and explain them.
