History

Project Looking Glass was originally created by Sun Microsystems as an experimental 3D desktop environment. This repository is a modernization port: the 2006-era Ant / JDK 1.5 codebase has been migrated to Gradle and JDK 21, and Sun's Java 3D has been replaced with the Jogamp-maintained fork.

About this Help Center

This guide is rendered by a JavaHelp viewer embedded in a Swing panel, hosted on a SwingNode in the 3D desktop or as an internal frame in the 2D desktop. Its topics, table of contents, keyword index and full-text search database are built from the help content bundled with the desktop.
