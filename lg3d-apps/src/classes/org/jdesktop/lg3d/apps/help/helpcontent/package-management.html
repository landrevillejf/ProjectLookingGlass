Managing Packages

The LPM Console is a graphical front end for the lpm package manager. It is a plain Swing application, so it runs as a desktop window in 3D and as an internal frame in the 2D desktop. Open it from the Start Menu under Utilities.

What it does

  • Lists installed packages and their details.
  • Runs lpm operations on your behalf and shows the output.
  • Provides a point-and-click alternative to typing lpm in a terminal.

The console works by invoking the system lpm executable, so the operations it can perform and the privileges it needs are exactly those of lpm itself.

Note: If lpm is not installed on the host, the console cannot carry out package operations. Install the package manager first, or use your distribution's own tooling.
