Security and Privacy

lg3d gathers its defenses into a small set of applications that work together. The Security Center is the hub: it grades your posture, advises how to harden it, and ties together the two anonymity layers — Private (Tor) mode and the VPN client. Alongside them sit the Firewall, the Password Manager and Backup. All run in the 3D desktop and in the 2D and Swing desktops.

Note: The desktop ships no virus engine, Tor binary or tunnel stack of its own. These tools delegate honestly to real, installed software (ClamAV, tor, nmcli / openvpn / wg-quick) and report truthfully when a tool is missing or a privilege is lacking — they never fake a “connected” or “clean” result.

The Security Center

Open Security Center from the System group of the Start Menu. It has several tabs:

  • Overview — a headline security grade from A to F (coloured green / amber / red), computed from six defense-in-depth checks: SELinux enforcing, the firewall running, an antivirus scanner installed, its definitions current, Private (Tor) mode on, and a VPN tunnel up with its kill switch armed. A posture grid below lists each check, now including Private (Tor) mode and VPN tunnel rows.
  • Antivirus — scan files or folders with the installed ClamAV, and update its definitions (freshclam).
  • Privacy — the Private (Tor) mode controls, described below.
  • Activity — an append-only audit trail recording every scan, definition update, posture read, private-mode transition, network cut and VPN tunnel change (capped at the most recent 500 entries).

The hardening advisor

The Overview lists recommendations, worst-first, each with a severity and an action. Select one and press Remediate to act on it: jump to the relevant tab, run freshclam, re-probe the posture, or — where the fix lives outside the app — show honest guidance for what to do.

Private (Tor) mode

Private mode is a desktop-wide anonymity switch, in the Security Center's Privacy tab. Turning it on routes all desktop traffic through Tor and, crucially, fails closed:

  • Enable probes the Tor service, starts it (through polkit) if it is not running, then forces JVM and child-process traffic through the local SOCKS proxy.
  • A background monitor watches Tor. The moment Tor stops while the mode is on, the desktop cuts the network: because the proxy endpoint is now dead, every connection is refused rather than silently falling back to the clearnet, so a leak is impossible by construction.
  • Verify no leak checks your exit address through the proxy only and reports whether you are really on Tor.

External programs you launch inherit the proxy while the mode is on, and the Web Browser refuses remote navigation and shows an honest “connection cut” page while the network is cut.

The taskbar privacy indicator

On the 2D and Swing desktops the taskbar shows a shield glyph for the private-mode state — steady when on, dimmed while enabling, and red when the network is cut. Clicking it opens the Security Center; a cut also raises a warning toast. Its tooltip doubles as the aggregate security grade, tinting cautionary on a poor (D/F) grade.

The VPN client

The VPN app (in the Internet group) connects to a private network through NetworkManager (nmcli), OpenVPN or WireGuard. It is a production-grade tunnel client:

  • Profiles — create, edit, import and remove profiles (name, type, gateway, auto-connect and kill switch).
  • Live status — while the panel is open it polls the tunnel state every few seconds, so you see connect / disconnect without refreshing by hand.
  • Auto-reconnect — a profile marked auto-connect that drops unexpectedly is retried with exponential backoff (2 s up to a 60 s ceiling, capped at five attempts).
  • Kill switch — arm it per profile and an unexpected drop cuts the desktop's network clients (the same fails-closed seam Private mode uses), so traffic cannot leak to the clearnet. The cut lifts automatically on reconnect.
  • Verify tunnel — records your public egress address just before the tunnel comes up and re-checks it on demand, classifying the result as tunneled, leak or unreachable. An unchanged address is reported as a leak, never a false pass.

Firewall

Firewall (in the System group) shows the firewall status and active rules and lets you enable or disable it. It manages the host's packet-filtering rules and network security.

Password Manager

Password Manager stores passwords and secrets in an encrypted vault sealed with your own master password (PBKDF2 key derivation plus AES-GCM encryption). Only the ciphertext is written to disk; the derived key and the decrypted entries live in memory while the vault is unlocked and are cleared on lock or auto-lock.

Backup

Backup archives the folders and files you choose to standard ZIP backups and restores them. It keeps profiles of sources and a destination, supports glob excludes, writes archives atomically, and hardens restore against path-traversal (“Zip-Slip”) attacks.

Tip: The Security Center grade is a quick at-a-glance summary, not a guarantee. Read the recommendations and the activity log to understand what is protecting you — and what is not installed.
