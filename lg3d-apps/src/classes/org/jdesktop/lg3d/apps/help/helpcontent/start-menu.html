The Start Menu

The Start Menu is how you launch applications. Open it from its button on the taskbar. Applications are grouped by category, so you can scan a short list rather than one long one.

Menu groups

The desktop defines these groups:

GroupTypical contents
Internet Web Browser, Mail, chat, FTP, SSH, VPN and other network tools — see Internet and the Web.
Office Mail, Agenda, Contacts, PDF Viewer and the organisation chart — see Office and Productivity.
Media Audio and video players, photos, image editing, recording — see Music, Photos and Video.
GamesChess, Solitaire, Sudoku and Tic-Tac-Toe.
EducationReference tools such as the Periodic Table.
Developers IDE, Git GUI, Database Manager, Docker Manager and API tools.
System Control Center, File Manager, Task Manager, Security Center, Firewall, Backup, Password Manager and the LPM Console — see Security and Privacy.
Utilities Calculator, Help Center, Archive, Search, Weather, Software Update, Media Writer, Widget Gallery and similar helpers.

A full list of every application, with where each one runs, is in Built-in Applications.

Note: On the 2D and Swing desktops each category folder now carries a recognisable icon (Internet, a web glyph; Media, a film glyph; System, a host glyph; and so on) instead of a bare text label, matching the iconned application entries inside it and honouring your active icon pack.

Launching an application

Click a group to expand it, then click an entry. Most entries launch inside the desktop's own JVM and open as a window; a few start an external program as a separate process. If an entry's external program is not installed, the menu simply does not show it.

Searching the menu

On the 2D and Swing desktops the Start Menu opens with a search field across the top: start typing to filter every application live to a short ranked list, press Enter to launch the top match, or clear the field to bring back the category tree. You can also press Alt+F2 anywhere in the desktop to open the run-command box and launch an application by name. See The 2D and Swing Desktops.

Tip: The Help Center lives under Utilities. Pinning it open while you explore is a good way to learn the desktop.
