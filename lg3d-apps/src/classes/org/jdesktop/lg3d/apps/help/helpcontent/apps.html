Built-in Applications

lg3d ships a set of sample and utility applications. Those whose interface is a plain Swing panel run in both the 3D desktop and the 2D desktop; the table notes where each one appears.

ApplicationWhat it does3D2D
Help Center This JavaHelp-based user guide.YesYes
Calculator Scientific calculator with expression history and a memory register.YesYes
File Manager Browse and manage files and folders.YesYes
Task Manager Inspect running processes.YesYes
Control Center Appearance, display, desktop and system settings. YesYes
Media Writer Write images to removable media.YesYes
Widget Gallery Browse and place desktop widgets. YesYes
LPM Console Graphical front end for package management. YesYes
Paint Simple drawing application.YesBeside

"Beside" means the app shows its own conventional window next to the 2D desktop rather than as an internal frame inside it.

The legacy sample help

A small demonstration app called Simple Sample Help also ships in the Start Menu. It predates this Help Center and shows a single static usage image in a custom-decorated 3D window; it is kept as a scene-graph example. For real documentation, use the Help Center.
