Built-in Applications

lg3d ships around fifty applications, grouped in the Start Menu by category. This page is the master index; the four categories with the most to say have their own topic: Internet and the Web, Security and Privacy, Music, Photos and Video and Office and Productivity.

The 3D and 2D columns say where each app runs. Almost every app is a plain Swing panel that works in the 3D desktop and as an internal frame in the 2D and Swing desktops. Beside means the app shows its own conventional window next to the 2D desktop rather than inside it; No means it needs the 3D desktop.

Samples and early prototypes

A set of 3D-only samples, tutorials and early prototypes also ship in the Start Menu (for example a 3D clock, a game-of-life grid, an image viewer and various scene-graph demonstrations). They are kept as programming examples rather than daily-driver tools, and they need the 3D desktop. The legacy Simple Sample Help — a single static usage image in a custom-decorated 3D window — predates this Help Center and is kept only as a scene-graph example; for real documentation, use the Help Center.
