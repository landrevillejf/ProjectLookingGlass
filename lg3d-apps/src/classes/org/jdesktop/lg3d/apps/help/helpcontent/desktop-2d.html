The 2D and Swing Desktops

Alongside the 3D desktop, lg3d offers two conventional desktops. Both are MDI (multiple-document-interface) shells: applications open as internal frames inside the desktop window, so they stay integrated and minimize into the desktop rather than escaping to the host system.

ModeLauncherLook and feel
2D desktop-2 / --2d The host system look and feel.
Swing desktop-w / --swing The cross-platform Metal look and feel.

The two are identical apart from the look and feel: same wallpaper pane, same internal-frame hosting and de-duplication, same Start Menu, folder menus, taskbar, and application launches.

When you get the 2D desktop automatically

If a machine cannot run Java 3D, the desktop detects this at start-up and offers the 2D desktop instead (after a confirmation prompt). Explicitly passing -2 or -w forces that mode with no prompt.

Applications in 2D

Applications whose user interface is a plain Swing panel — the File Manager, Task Manager, Control Center, Calculator, Media Writer, Widget Gallery, LPM Console and this Help Center — are hosted as internal frames in the 2D desktop. Purely 3D applications are marked "Requires the 3D desktop" and are not offered.

Note: A conventional top-level window cannot be adopted by an MDI desktop, so apps that insist on showing their own frame run beside the 2D desktop rather than inside it.

Beyond hosting applications, the 2D and Swing desktops add a set of everyday conveniences — live Start Menu search, window snapping, a keyboard window switcher, desktop-wide shortcuts, a run-command box, notifications, taskbar system indicators, a clock calendar and session restore. Each is described below; all of them behave the same in the 2D and the Swing desktop.

Searching the Start Menu

The Start Menu opens with a search field across the top. Start typing and every configured application is filtered live into a single ranked list: an exact name match comes first, then a name that starts with what you typed, then a word-boundary match (man in File Manager), then any other name match, and lastly a match found only in the description or command. Ties keep the original menu order, and at most a dozen results are shown so the list stays short. Press Enter to launch the top match or Esc to close; clearing the field brings back the normal category tree.

Snapping windows to the screen edges

Drag an application window to the edge of the desktop and release to snap it: the left or right edge tiles the window to that half of the screen, and the top edge maximizes it. While the pointer is inside the edge zone a translucent preview shows the rectangle the window will take. The edge zone is 48 pixels wide by default and is configurable.

Switching between windows

Press Alt+` (Alt and the grave / backtick key) to raise a translucent overlay that lists the open windows in most-recently-used order and steps a highlight through them; Alt+Shift+` steps the other way. Release the keys and pause briefly, and the highlighted window is brought to the front — there is no separate confirm key.

Note: The switcher deliberately uses Alt+` rather than Alt+Tab. The 2D desktop is an ordinary window under your host window manager (GNOME/Mutter, Xwayland), which grabs Alt+Tab, Super+Tab and the Ctrl+Alt+arrow workspace keys before they ever reach the desktop.

Global keyboard shortcuts

These work anywhere in the desktop while its window has the focus:

KeysAction
Ctrl+Alt+D Show the desktop (minimize all windows).
Alt+Shift+Left / Alt+Shift+Right Snap the focused window to the left / right half.
Alt+Shift+UpMaximize the focused window.
Ctrl+Alt+TOpen a terminal.
Ctrl+WClose the focused window.
Alt+F2Open the run-command dialog.
Alt+` / Alt+Shift+` Cycle through the open windows.

Combos that the host window manager reserves for itself (Super+key, Ctrl+Alt+arrow) are intentionally left alone, so the desktop never fights your system.

The run-command dialog (Alt+F2)

Press Alt+F2 to open a small run box. Type the name of a Start Menu application to launch it, or type an external command (for example xterm or firefox --private-window) to run it as a separate process. Enter runs it, Esc closes the box, and Up / Down recall the last 20 entries, which are remembered between sessions. If what you typed matches no application and is not an available command, the box stays open and says so, letting you correct it.

Notifications and toasts

The taskbar carries a Notifications button with a live unread badge. Click it to open the list of notifications raised so far — newest first, tinted by severity — then click one to dismiss it, or choose Clear all to empty the log; opening the list marks everything read. When a notification arrives it also pops as a small toast card stacked up from the bottom-right corner, which fades after a few seconds or dismisses on a click. Because an application that opens beside the desktop has no taskbar button of its own, launching one raises an info notification so you can see that it started.

Do Not Disturb quiets the desktop without losing anything. Turn it on from the Notifications pop-up (the Do Not Disturb checkbox, or Do Not Disturb for 1 hour to have it lapse on its own) or from the desktop right-click menu. While it is on the tray button is prefixed with [DND] and new notifications stop popping as toasts — but they are still recorded in the list, so nothing is missed. Error notifications always break through. The setting is remembered between sessions; a timed “for 1 hour” period that has already elapsed comes back off on the next start.

To the left of the clock sits a small system tray with live volume, brightness, network and battery glyphs, each with a detailed tooltip:

The readings refresh on their own — volume every second, brightness, network and battery every five seconds. Everything degrades gracefully: with no sound card, no controllable backlight, no battery, or on a non-Linux host, the corresponding glyph is simply hidden rather than showing nonsense.

The clock and its calendar

Click the taskbar clock to open a calendar above it. The month grid runs Monday-first with today highlighted and the neighbouring months' days dimmed at the edges; « and » step through the months. A small agenda footer lists the notifications raised today, or reads “No events today”.

Restoring your session

The desktop remembers which application windows were open when you last exited and reopens them on your next start — at their saved size and position, in their saved minimized / maximized state, and back-to-front so the original stacking order is kept. Every restored window is clamped back on-screen, so a session saved on a larger or differently arranged monitor never strands a window off-screen. Only windows that can be relaunched from a Start Menu descriptor are remembered; an app that has since become unavailable is skipped quietly rather than greeted with an error dialog at start-up.
