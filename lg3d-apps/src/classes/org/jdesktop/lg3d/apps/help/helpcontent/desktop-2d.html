The 2D and Swing Desktops

Alongside the 3D desktop, lg3d offers two conventional desktops. Both are MDI (multiple-document-interface) shells: applications open as internal frames inside the desktop window, so they stay integrated and minimize into the desktop rather than escaping to the host system.

ModeLauncherLook and feel
2D desktop-2 / --2d The host system look and feel.
Swing desktop-w / --swing The cross-platform Metal look and feel.

The two are identical apart from the look and feel: same wallpaper pane, same internal-frame hosting and de-duplication, same Start Menu, folder menus, taskbar, and application launches.

When you get the 2D desktop automatically

If a machine cannot run Java 3D, the desktop detects this at start-up and offers the 2D desktop instead (after a confirmation prompt). Explicitly passing -2 or -w forces that mode with no prompt.

Applications in 2D

Applications whose user interface is a plain Swing panel — the File Manager, Task Manager, Control Center, Calculator, Media Writer, Widget Gallery, LPM Console and this Help Center — are hosted as internal frames in the 2D desktop. Purely 3D applications are marked "Requires the 3D desktop" and are not offered.

Note: A conventional top-level window cannot be adopted by an MDI desktop, so apps that insist on showing their own frame run beside the 2D desktop rather than inside it.
