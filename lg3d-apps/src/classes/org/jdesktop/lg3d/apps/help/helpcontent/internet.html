Internet and the Web

The Internet group of the Start Menu holds the desktop's networked applications: a full-featured web browser, a real mail client, chat, video conferencing, file transfer, secure shell, remote desktops and a VPN tunnel. Every one of them is a plain Swing application, so each runs both in the 3D desktop and as an internal frame in the 2D and Swing desktops.

The Web Browser

The Web Browser is a daily-driver, tabbed browser built on the JavaFX WebView (WebKit) engine. It resolves what you type in the address bar intelligently: a web address is opened directly, host-like text is prefixed with https://, and anything else is handed to your chosen search engine.

Note: The browser looks different in each desktop, on purpose. In the 2D and Swing desktops the Start Menu entry opens the full interactive browser inside an internal frame. In the 3D desktop it opens a branded preview card whose Open Full Browser button launches the real browser in its own window — because a WebKit surface cannot be painted into a 3D texture. Either way you end up with the same browser.

Tabs and navigation

The toolbar carries back, forward, reload, stop and home, and the tab strip gives each tab its own close button. Common actions have keyboard shortcuts:

KeysAction
Ctrl+TOpen a new tab.
Ctrl+WClose the current tab.
Ctrl+LJump to the address bar.
Ctrl+RReload the page.
Ctrl+FOpen the find bar.
Ctrl+Tab / Ctrl+Shift+Tab Next / previous tab.

Search engines

Eight search engines are built in and selectable from the browser settings: DuckDuckGo (the default), Google, Bing, Startpage, Brave Search, Ecosia, Mojeek and Wikipedia.

Find in page

Press Ctrl+F (or click Find) to dock an inline find bar. Every match is highlighted and the bar shows a live “n of m” count; Enter jumps to the next match, Shift+Enter to the previous, and Esc closes the bar and clears the highlights.

Reader mode

Click Reader to extract the main article from the current page and reopen it, clean and ad-free, in a new tab — handy for long-form reading and for printing.

The address-bar security indicator

A clickable indicator beside the address bar classifies the current site as secure (HTTPS), not secure, local or internal. Click it to open a site-information popup showing the connection security, host and scheme, the JavaScript and cookie state, and how many navigations and pop-ups the browser blocked for that site.

Bookmarks, history and downloads

  • Bookmarks — star a page to bookmark it; the bookmarks menu reopens it. Bookmarks are stored by address, so starring the same page twice does not duplicate it.
  • History — recently visited pages are recorded (de-duplicated and capped). Clear it from the browser settings.
  • Downloads — non-renderable content downloads with a progress bar and a per-row Cancel button. Stalled downloads time out rather than hanging forever.

Settings, privacy and extensions

The settings dialog controls JavaScript, cookies, the user agent, page and download timeouts, and offers Clear history and Clear cookies. A private browsing option keeps cookies only for the session.

An Extensions button opens the extension manager. A few reference extensions ship built in — a pop-up blocker, a tracker blocker and an HTTPS-upgrade helper. Third-party extensions start disabled with no permissions until you approve them.

Note: Extension permissions are a consent prompt, not a sandbox: an extension runs with your own privileges once loaded, so install only extensions you trust.

When the desktop-wide Private (Tor) mode is on, the browser forces a non-persisting cookie session; if the Tor tunnel is cut, it refuses remote navigation and shows an honest “connection cut” page rather than silently leaking to the clearnet.

Mail

Mail is a real IMAP / SMTP client: it connects to your mail server, lists folders, reads and composes messages, and sends them over SMTP. It shares the desktop's Contacts address book.

Instant Messenger

Instant Messenger is a multi-protocol chat client. It includes a fully native IRC client and bridges to other networks, with an accounts list, a conversation view and a scrolling transcript.

Video Conference

Video Conference joins and hosts Jitsi Meet calls. It provides a lobby and an address book, builds the meeting link, and hands the live audio/video session to the system browser (or an external meeting command).

FTP Client

FTP Client transfers files over FTP, FTPS and SFTP, with a two-pane local/remote view and a transfer queue.

SSH Client

SSH Client opens interactive terminal sessions over SSH to a remote host.

Remote Viewer

Remote Viewer shares and views remote desktops, with clipboard synchronisation and file transfer. It can act as the server (start/stop and status) or connect out to a remote session as the viewer.
