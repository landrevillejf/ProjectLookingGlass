## What

Three Espresso (text editor) polish items from the latest screenshot:

1. **Closable tabs** — every editor tab now carries a custom header with a small **×** button (plus the existing dirty dot). The tab index is resolved at click time, so closing one tab never mis-closes its neighbour. Ctrl+W and middle-click still work; the unsaved-changes confirmation is unchanged.
2. **Project tree starts on the file system** — `ProjectTreePanel` was showing Swing's stock `JTree` demo model (`colors` / `sports` / `food`) before any document was opened. It now boots with an empty model and re-roots on `defaultStartRoot()` (the user home when readable, else the first file-system root).
3. **Espresso cup icon instead of an "ES" tile** — the 2D desktop rendered the branded cup PNG as a generated initials tile because `AppIcons` only shows a descriptor PNG when it is in `DESCRIPTOR_ICON_PREFERRED` and "Espresso" matches no semantic family. `espresso.png` joins the launcher rocket in that set, so the window frame, taskbar button and start menu all show the cup the 3D desktop already carries.
