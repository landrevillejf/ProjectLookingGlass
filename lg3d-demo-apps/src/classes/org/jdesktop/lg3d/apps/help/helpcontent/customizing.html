Customizing the Desktop

Most day-to-day customization is done through the Control Center (Start Menu → System). It gathers appearance, display and desktop settings in one place.

Control Center panels

  • Appearance — fonts and the look of the desktop.
  • Display — display-related settings.
  • Desktop — wallpaper and desktop behaviour.
  • Users — user account information.
  • System Info — details about the running system.

Wallpapers and backgrounds

The desktop background can be one of the bundled wallpaper images, or a 3D model. Launch with -b (or the Gradle property -Pbackground3d) to use the 3D model background (pinguin.j3f) instead of a flat image. The taskbar and windows sit in front of whichever background is active.

Fonts

The configured Swing font (family and size) is applied to hosted application panels, so changing it in the Control Center re-skins the text across the desktop's Swing windows — including this Help Center. Resetting to the default restores the active look and feel's own fonts.

Tip: Changes made in the Control Center apply live; you do not need to restart the desktop to see them.
