Welcome to Project Looking Glass

Project Looking Glass (lg3d) is a three-dimensional desktop environment originally created by Sun Microsystems and now maintained as a modernized port running on JDK 21 with Jogamp Java 3D. Instead of flat, stacked rectangles, windows live as panels in a 3D space you can move, rotate, flip and park — while everyday Swing applications run right inside it.
